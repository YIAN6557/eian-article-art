# 例子：《从使用者到创作者：7 步从 0 做出属于自己的 Skill》配图清单

这是第二篇整篇配图的最终清单（作者认可）。原文约 3200 字，本来有 4 处“图像”占位，作者要求全部换成新图，再加 1 张。这个文件夹只放了封面、fig1 和 fig5 当例子。

| 文件 | 放在哪段后面 | 讲哪件事 | 画面 | 图上的字 |
|---|---|---|---|---|
| cover | 文章最上面 | 把自己的经验写成 Skill | 小人拿铅笔在一本大说明书上画流程图 | 从使用者到创作者 / 7 步从 0 做出属于自己的 Skill |
| fig1-structure | 第 1 处“图像”：一个 Skill 的标准骨架（模块）大致如下 | 五个模块，哪个必需、哪个可选 | 一排五样：小人捧手册、书架、齿轮、两张样例纸、物料箱 | SKILL.md / references / scripts / examples / assets，各带“必需/可选”和原文比喻 |
| fig2-card-brain | “SKILL.md 只放做决策必须知道的东西”之后 | 对外是名片，对内是大脑 | 左：小人举名片；右：小人站在岔路口指路 | 对外是「名片」/ 对内是「大脑」 |
| fig3-cooperation | 第 2 处“图像”：再串一遍，一个任务进来之后发生了什么 | 五个模块怎么配合 | 读手册 → 查资料、整理材料 → 套模板输出 | SKILL.md / scripts · references · examples / assets |
| fig4-progressive | 第 3 处“图像”：渐进式披露，一共分三层 | 三层读取 | 看封面 → 读正文 → 从书架拿资料 | 名字和 description / SKILL.md 正文 / 按需读取 |
| fig5-seven-steps | 第 4 处“图像”：一共7步 | 七个步骤 | 上四下三，七个小图 | 1 梳理流程 … 7 迭代（每个一行） |

排字的两种做法：
- `fig5-seven-steps.html`：7 个小图，每个标签一行、放在小图正下方，没有总标题。
- `fig1-structure.html`：5 个小图，每项要写名字、必需/可选、比喻三样东西，所以每个标签三行；五个都是三行，行数一样。
