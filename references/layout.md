# 排字（加字那一步用）

- 认可过的模板都在 `examples/`：中文 7 个、英文 7 个（`*_en.html`）；`examples/article2/` 是第二篇整篇配图，有配图清单、5 个模块的结构图、7 步图的排字。照抄比从头写好。
- **一张图有 4 个以上小图**（比如 5 个模块、7 个步骤）时：
  - 每个标签尽量只写一行，照原文缩短到 6 个字以内（例：“写成自然语言步骤”→“写成步骤”）。
  - 标签放在自己那个小图的正下方，先量出每个小图在画里的中心 x 再定位置。
  - 前一句已经说了总数（如“一共7步”）就不加总标题，把空间留给画。
  - 每项一定要写几样东西时（比如名字 + 必需/可选 + 比喻），可以多行，但每项行数一样（见 `examples/article2/fig1-structure.html`）。
- 标签不要被硬拆成两行、第二行又变成小字（看起来像解释，其实是半句话）。
- 图上的字照文章原话缩短，不要自己编新说法；英文图也是，用文章里的英文原词。
- 画的位置不对时改 HTML，不用重画：
  - 构图要落到黄金比例线上时，AI 经常放不准。用 CSS 把小人挪过去（见 `examples/fig4.html`）。
  - 图画得偏上或偏下，改 `.a` 的 `top`（见 `examples/fig2.html`）。
  - 封面的画太小，把 `#art` 放大、往上挪（例：width 1300、height 867、top -70）。
