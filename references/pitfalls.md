# 画图踩过的坑（写提示词前看一遍，画坏了再看一遍）

- 提示词里一定要写 “Do not copy ...”，列出参考图里的物件，不然它们会被带进新图。
- 方块、卡片这种干净的物件最容易跑风格，变成细直线框。提示词里要写明：drawn with the same tangled scribble lines, with light and shadow, not a thin wireframe。
- 只带小人参考图、不带线条参考图时，画会变得太光滑、像毛毡，边上有白色光晕。两张参考图每次都要带。
- 人物总画不好时，不要加更多文字描述，换一张更好的小人当参考图再画。《反应要有先后》那张试了三次，用四人图当参考才对。
- 人物动作写成身体怎么摆（脚分开、膝盖弯、双手抓住把手往上推），不写情绪词（开心、着急）。
- 封面的画常常画得太小、上下空太多。提示词里写清楚撑满左半边、从上 4% 到下 96%。
- 一次只画一张。几张一起画，容易拿错图，也容易互相串风格。
